🌱 EecoQuest
An interactive and engaging web app that empowers users to explore, track, and adopt sustainable daily habits.

🔗 Live Demo: eecoquest.netlify.app

✨ Features
➕ Add Quests — Quickly add personal eco-challenges and daily green habits
🏷️ Categorize Actions — Organize activities into Energy, Waste, Transport, Food, and Lifestyle
📊 Real-Time Impact — Instantly track completed quests, total carbon savings, and streak count
🔍 Filter Challenges — View tasks by category for targeted habit building
🗑️ Reset Progress — Clear completed tasks or reset your eco-tracker with one click
📱 Responsive Design — Works smoothly across devices

🛠️ Built With
HTML5
CSS3
JavaScript

🚀 Getting Started
Clone the repository
   git clone https://github.com/your-username/eecoquest.git
Open index.html in your browser
Start taking steps toward a greener future!
